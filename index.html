1. The Skeleton of Every Page

A basic HTML page has this structure. Learn this shape once — you will type it often.

<tag> content </tag>

🟣 opening tag   |   content sits inside   |   🔴 closing tag has a /

🟠 index.html
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    Hello World
  </body>
</html>
➜
🔵 Browser tab
📄 My Page
Hello World
1
<html> — wraps the WHOLE page. Everything lives inside it.
2
<head> — hidden info. Only the <title> shows (in the browser tab).
3
<body> — everything people actually SEE on the page goes here.

🔍 Spot the difference

❌ Broken
<body>
  Hello World
</html>
Missing </body> — the closing tag doesn't match!
✅ Fixed
<body>
  Hello World
</body>
</html>
Most HTML tags have an opening and matching closing tag. Some tags, like <br> and <img>, do not.

3. Lists

Two kinds of lists: one with numbers (order matters), one with dots (order doesn't matter).

🟠 Unordered (dots)
<ul>
  <li>Pune</li>
  <li>Delhi</li>
  <li>Bangalore</li>
</ul>
➜
🔵 Result
  • Pune
  • Delhi
  • Bangalore
🟠 Ordered (numbers)
<ol>
  <li>Somesh</li>
  <li>Rohit</li>
  <li>Vishakha</li>
</ol>
➜
🔵 Result
  1. Somesh
  2. Rohit
  3. Vishakha

💡 <ul> = Unordered List (dots)   |   <ol> = Ordered List (numbers)   |   <li> = one List Item, goes inside either one

🔍 Spot the difference

❌ Broken
<ul>
  Pune
  Delhi
</ul>
Text is loose inside <ul> — missing <li> wrapper for each item.
✅ Fixed
<ul>
  <li>Pune</li>
  <li>Delhi</li>
</ul>
Every list item needs its own <li>...</li>.
🟣 Try it yourself
🔗

4. Links & Images

These two tags don't have plain text between them — they use an attribute (extra info) to say where to link or which picture to show.

<img src="sun.jpg">

🔵 attribute name  =  🟢 value in quotes

🟠 Image
<img src="sun.jpg" width="100">
➜
🔵 Result
☀️
🟠 Link
<a href="https://w3schools.com">
  Visit W3Schools
</a>
➜
🔵 Result
Visit W3Schools
👆 clicking this takes you to another page

🔍 Spot the difference

❌ Broken
<img src=sun.jpg>
Missing quotes around the image file name — the browser gets confused.
✅ Fixed
<img src="sun.jpg">
Attribute values always go inside "quotes".
🟣 Try it yourself

This activity uses an embedded picture so it works offline. On a normal website, src usually contains an image file name, such as sun.jpg, or a web address. Send a local image file in the same folder as the HTML file.

5. CSS: Coloring & Styling

HTML builds the page. CSS makes it pretty. CSS rules live inside <style> in the head.

h1 { color: pink; }

🎯 which tag   |   🔵 property   |   🟢 value   |   put ; after each property

🟠 Code
<style>
  h1 {
    color: orange;
  }
  body {
    background-color: skyblue;
  }
</style>
➜
🔵 Result

Colorful Title

🖌️
color
Text color
🪣
background-color
Fill color behind
📏
width / height
Size of a box
🖼️
border
Outline around a box
🔵
border-radius
Rounds the corners
🎯
text-align
left / center / right

Borders — 3 pieces working together:

🟠 Code
div {
  border-style: dotted;
  border-color: green;
  border-width: 5px;
}
➜
🔵 Result
A box!

🔍 Spot the difference

❌ Broken
h1 {
  color: pink
}
Missing the semicolon ; after pink. We put ; after each CSS property to mark the end of the declaration.
✅ Fixed
h1 {
  color: pink;
}
The semicolon tells CSS "this rule is done."

6. Boxes & Layout (div)

<div> is an invisible box. You group things inside a div, then use CSS to place boxes side-by-side, like arranging furniture in a room.

🟠 Code
<div id="left">
  <h3>Box 1</h3>
</div>

<div id="right">
  <h3>Box 2</h3>
</div>

<style>
  #left  { float: left;  width: 50%; background: pink; }
  #right { float: right; width: 50%; background: lightgreen; }
</style>
➜
🔵 Result
Box 1
Box 2

3 boxes, adding up to 100% width:

40%
30%
30%
📦
div
An invisible container box
⬅️➡️
float
Can place boxes beside each other
📍
position
relative / absolute placing
🏷️
id="name"
Gives a box a unique name to style with #name

🔍 Spot the difference

❌ Broken
<style>
  left { float: left; }
</style>
<div id="left">...</div>
CSS says left but should say #left — the # means "an id named...".
✅ Fixed
<style>
  #left { float: left; }
</style>
<div id="left">...</div>
Match the # + id name exactly to the div's id="...".
🟣 Try it yourself

7. Video & Sound — Seen, Not Heard

You can put video and sound on a page too. We focus on video because it's visual. Add captions to video, and a transcript or text alternative for audio so everyone can understand it.

🟠 Code
<video controls
       width="400px">
  <source src="your-video.mp4"
          type="video/mp4">
</video>
➜
🔵 Result
🎞️
▶️ 🔊 ⛶

This lesson uses the visual player mockup below, not a hidden video file. A real video must be supplied alongside the HTML file.

🔊 What about sound-only (<audio>)?

🟠 Code
<audio controls>
  <source src="song.mp3"
          type="audio/mp3">
</audio>
➜
🔵 What shows on screen
A player bar appears — no picture, just a play button. Give sound content a transcript or visible text alternative nearby. 💬
  • controls — shows play/pause buttons on screen
  • width / height — the size of the video box
  • <source> — tells the browser where the file is
  • Pair video with captions, and audio with a transcript or visible text alternative 👀

8. Forms — Collecting Answers

Forms let people type answers and press Submit. Every input has a <label> — the visible question text — connected to it.

🟠 Code
<form>
  <label for="name">Name:</label>
  <input id="name" type="text"><br>

  <label for="email">Email:</label>
  <input id="email" type="email"><br>

  <button>Submit</button>
</form>
➜
🔵 Result

for="name" connects the label to id="name". Tapping a label then focuses its answer box.

🏷️
label
The question text
⌨️
input type="text"
A typed answer box
📧
input type="email"
Checks for a valid email
📅
input type="date"
A date picker
🔢
input type="number"
An input designed for entering numbers
✅
required
Must be filled before submit

🔍 Spot the difference

❌ Broken
<form>
  <label>Name:</label>
  <input type=text>
</form>
The quotes are missing around text. Attribute values should be written inside quotation marks.
✅ Fixed
<form>
  <label for="name">Name:</label>
  <input id="name" type="text">
</form>
Same rule as always: attribute values need "quotes".
🟣 Try it yourself
